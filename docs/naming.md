# Optional: giving the agents call signs

The structure uses plain role names everywhere, and that is what you dispatch on. Some teams like short call signs for conversation; they are purely a naming flavor and never a valid agent identifier.

The setup this blueprint was extracted from used Transformers names: Optimus Prime for the orchestrator, Jetfire for the dev manager, Prowl for the product manager, Ratchet for backend, Windcharger for mobile, Red Alert for QA, and Ultra Magnus for release. If you borrow franchise names, keep them private: they are trademarks of their owner, and a public product should use original names.
