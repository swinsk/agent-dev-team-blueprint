# Spec Kit templates: source and changes

These templates and command instructions come from GitHub Spec Kit (https://github.com/github/spec-kit), commit 381ce3b (2026-10-09), under the MIT License; the licence text is in `LICENSE-spec-kit` beside this file. Copyright GitHub, Inc.

Files: `spec-template.md`, `plan-template.md`, `tasks-template.md`, `checklist-template.md`, `constitution-template.md`, and Spec Kit's step instructions saved as `command-<step>.md` (specify, clarify, plan, tasks, analyze, checklist, implement, constitution).

Changes made here: em and en dashes were replaced with commas, colons or hyphens to satisfy this repo's style check. Nothing else was edited. The command files reference Spec Kit's own CLI scripts and folder layout; this blueprint uses the method and templates without requiring the CLI (see `patterns/spec-driven.md`), so read them as the reference for what each step must produce.
